# Автообновление резюме

В меню `/start` есть кнопки «Включить автообновление резюме» и
«Отключить автообновление резюме». Команды: `/resume_on`, `/resume_off`.
Пользователь подключает личный аккаунт через `/connect_hh`, затем выбирает
одно опубликованное резюме. Бот обновляет дату публикации, не текст резюме.

Первая попытка выполняется в течение минуты. Следующие — не раньше чем через
5 часов после успешного обновления. Если HH запрещает обновление, попытка
откладывается. Скрытые и неопубликованные резюме автоматически не публикуются.
Ошибки доступа отключают расписание с уведомлением пользователя.

Настройки и время следующего обновления хранятся в БД и переживают перезапуск.
При запуске создаётся таблица `resume_auto_updates` (существующие таблицы не
меняются). Если у пользователя БД нет права CREATE TABLE, администратор должен
предварительно выполнить `migrations/add_resume_auto_updates.sql`.

Для работы нужны существующие настройки `BOT_TOKEN`, `DATABASE_URL`,
`HH_CLIENT_ID`, `HH_CLIENT_SECRET`, `HH_REDIRECT_URI`, `HH_API_HH_USER_AGENT`.
OAuth callback должен быть доступен снаружи по настроенному redirect URI.
Бот должен непрерывно работать на сервере: закрытый локальный процесс не
выполняет расписание. Платные услуги HH автоматически не подключаются.

Проверка без внешних запросов и без рабочей БД:

```sh
python -m unittest test_resume_updates -v
```

Локальные тесты используют SQLite и подменённые ответы HH. Проверку с реальным
аккаунтом HH нужно выполнить после установки на сервер и авторизации.
